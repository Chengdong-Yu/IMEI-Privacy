# HyperOS IMEI Privacy Shield

基于 LSPosed 的设备标识隐私模块，包含 Miuix 状态与设置界面。

最低支持 **Android 13** 目前仅适配HyperOS/MIUI，经过HyperOS 4 CN以及Global实测

## 当前版本功能

- **IMEI / MEID 伪装：** 为双卡提供稳定的伪标识，覆盖常见 Telephony、Binder、系统属性以及已适配的 MIUI / Qualcomm 接口。此功能不读取或修改 modem 中的真实标识。
- **查找设备隐私保护：** 按当前进程加载的 DEX 语义发现接口，不依赖固定版本号或混淆类名。伪装设备序列号、型号、MAC、FID、Cloud ID、广告标识、SIM 与推送标识；过滤已覆盖请求中的相关字段，并屏蔽已适配的 OneTrack 统计、定位与无线扫描结果。小米账号身份不作修改。
- **自检与联网保护：** 检查已覆盖 Hook 和请求处理路径。查找设备默认保持联网阻断；当前采样进程自检通过后才放行。自检失败、状态过期、报告缺失或保护异常时重新阻断，也可配置为同时停用查找设备。
- **状态与控制：** 查看 root 授权、模块版本、关键 LSPosed 作用域和进程自检状态；手动刷新或重新自检。隐私总开关协调 Hook、系统属性覆盖及联网守护，分别显示本次启动与下次启动状态。
- **作用域与重启提示：** 检查系统软件的 LSPosed 配置；缺少配置时提示前往 LSPosed。保存需要重启生效的设置后，可确认重启设备。
- **隐私优先：** 界面不展示真实 IMEI。自检使用合成数据，不发送测试请求，也不触发定位、绑定或凭据更新。

## 运行条件与影响

需要 Android 13(MIUI14) 或更高版本，以及可用的 LSPosed 环境。功能依赖完整Magisk/KernelSU模块与 APK 配套运行。

保护仅覆盖已适配的接口和网络路径；自检通过不代表所有应用、native 代码或云端已有数据都受到保护。模块不修改 modem NV 或系统分区。
